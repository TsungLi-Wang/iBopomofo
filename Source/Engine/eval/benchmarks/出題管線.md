# 出題管線（新北極星題庫怎麼生出來的）

放在這裡是因為它描述的是這個目錄裡腳本的用法。**為什麼要這樣出題**（雙向鐵律、
無標點無空格、難度優先、EX1166 的界線）寫在 `docs/decisions/0002-新北極星是字級同音消歧的尺.md`。

評分機用法見 `README-newstar.md`。

---

## 三關

1. **AI 只生句子** —— 連續漢字，無注音、無標點、無空格（prompt 見下）。
2. **小麥線上注音工具**加注音。
3. **`make_newstar_jsonl.py`** 轉 JSONL —— 腳本自己認答案，零手動標記。
   換組只改檔頭 `GROUP` / `PAIR_READING` / `PAIR_ID`。

篩選／組批：`screen_newstar_batch.py`、`assemble_newstar_batch.py`
（`--balance keep-all`：**不要**硬砍等量，會把好題目一起丟掉）。

## 生成 prompt（範例為 在／再；換組改開頭的字與分配）

```
你是台灣繁體中文的母語使用者。請幫我生成一批測試「注音同音字選字」的句子。
【這組要考的同音字】在、再（讀音都是 ㄗㄞˋ）
【任務】
生 40 句自然、道地的台灣中文句子：一半的句子包含「在」、另一半包含「再」，混著排。
【硬規則】
1. 每句都是台灣人平常真的會講/會打的話（台灣用詞語氣，不要中國用語、不要教科書腔）。
2. 每句剛好包含「在」或「再」其中一個、且只出現一次；那個字用在這句裡一定是對的——換成另一個字整句會明顯錯或明顯怪。
3. 嚴禁模稜兩可：兩個字代進去都讀得通的句子，一律不要。
4. 【要難】盡量挑另一個字乍看也像會被用到的情境，但實際上只有一個字對。避免太簡單的句子。
5. 長度、句型、語氣要多變。
6. 不要任何標點符號，也不要空格——每句就是一段連續的字。需要停頓就當成另一句、換行寫。
7. 情境要散開，不要每句同一個場景。
【輸出格式】
只輸出句子本身，一行一句。不要注音、不要標點、不要空格、不要編號、不要解釋。
```

- 三路（是／事／式）：開頭改成三個字，任務改「平均分配三個」。
- 詞級（權力／權利）：目標改成多音節詞。

⚠️ **這份 prompt 生出來的題目不能拿來歸納規則或挑參數，然後再用同一份題目報成績。**
已經翻車兩次，見 `docs/dead-ends.md` B、C 節。

## 轉換腳本核心邏輯（`make_newstar_jsonl.py` 萬一遺失可重建）

輸入每行 ＝「句子（連續漢字）＋ 小麥注音」。

1. 用第一個注音符號切開「句子」與「注音」。
2. 句中屬於 `GROUP` 的字必須**剛好一個** → 該題答案；同組其餘字 ＝ 干擾字。
3. 注音每音節清成純注音符號＋聲調。
4. 健檢：音節數 ＝ 字數；答案位的讀音 ＝ `PAIR_READING`。不符就丟掉整句。
5. 輸出 JSONL，欄位契約：
   `sentence_id` / `sentence` / `target_index` / `target_char` / `wrong_chars` /
   `reading` / `pair_id` / `n_way` / `weight` / `tier` / `split` / `domain` /
   `full_reading` / `source`。

`single tier` ＝ 一句一個同音位，診斷骨幹；`multi tier` ＝ 一句多個同音位，第二層壓測。

**詞級題待補**：評分機要把「比對單一位置」改成「比對輸出整段 == 目標詞」（字級不受影響）。
