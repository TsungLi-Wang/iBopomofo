# tw538 錯字位置剖面（棒 A-2）

## 假設

「單字同音錯最需要右側上下文」。若錯字多落句尾，右側無料，雙向判別器價值下降。

## 一句話結論

**這批錯誤平均右側仍剩約 6.6～6.7 個字**；句末錯僅約一成。  
**右側上下文整體有料**——若未來做雙向／右文模型，資訊量並非結構性枯竭；但棒 A-2 閘門結論已否決「單點 v2c 翻字」路線，右文模型需另立假設與量測。
