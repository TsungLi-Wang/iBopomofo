## Tab 預覽怎麼試

1. 切到i注音，確認選單「神經路徑重排」**已勾**。  
2. 打一句組字區會選錯的長句（例如 dogfood 驗收句「百貨門市不適用」的注音，或你常用的錯句）。  
3. **先看組字底線上的字**（預覽 = walk 結果）。  
4. 按 **Tab**（不要按 Enter）：  
   - 底線還在（沒送出到 App）  
   - 組字文字可能「跳」成較正確的一句（~50ms 級，可接受）  
5. 再按一次 **Tab**：字不變、不閃。  
6. 繼續打下一個音節：剛才 Tab 釘住的字**不應被 walk 翻掉**。  
7. 按 **Enter**：送出（若 flag 開，會再走一次重排後 commit）。

### 手選至上

1. 組字中開候選窗，**手動選**一個字。  
2. 按 Tab。  
3. 你手選的那個字必須還在（不能被重排蓋掉）。

### 非組字 Tab

1. 組字區清空（或游標在一般文字欄、沒有底線）。  
2. 按 Tab → 應像平常一樣跳欄位／插入 tab，輸入法不吞掉。

### Enter 對照

1. 同一句不按 Tab、直接 Enter → 仍應送出重排後的結果（與 v2.6.0 行為一致）。

## 已知非 bug

- 組字預覽（未按 Tab/Enter）仍可能是 walk 錯字；智慧在 **Tab 預覽** 或 **Enter 送出** 才介入。  
- 句尾空白／失焦送出**不**跑神經重排（刻意維持小麥原版，本棒不補接）。  
- `~/Library/Application Support/McBopomofo/AIModel/model.gguf` 可能仍佔磁碟 ~2.9GB；程式已不再使用。可手動刪以回收空間（非必須）。
