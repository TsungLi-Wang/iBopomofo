# tw538 殘餘熵四格 + Fano 下界（棒 A-2）

## 熵前綴

**gold teacher-forcing**（非 walk 前綴）。見 `homophone_measure.cpp`。

## 固定門限四格（H≥1.0 高，H&lt;0.5 低）

|  | 位置答對 | 位置答錯 |
|--|----------|----------|
| **低熵** | ① **4701** 真的會 | ② **58** 學錯了 |
| **中熵** (0.5≤H&lt;1) | 738 | 54 |
| **高熵** | ③ **1123** **矇對** | ④ **125** 真的不會 |

**③ 矇對**：1123 / 6562 答對位置 = **17.1%** 的答對來自 H≥1.0。  
占全體 6799 位置的 **16.5%**。  
解讀：387 分並非處處高把握；有一批「模型不確定卻猜對」的位置，分數有脆弱面。

## 分位門限（全體 H 三分位）

- 低：H &lt; 0.01325  
- 中：0.01325 ≤ H &lt; 0.3868  
- 高：H ≥ 0.3868  

|  | 答對 | 答錯 |
|--|------|------|
| 低熵 | 2260 | **6** |
| 中熵 | 2220 | 46 |
| 高熵 | 2082 | **185** |

**結論方向不翻轉**：答錯高度集中在相對高熵（185/237≈78% 落在上三分位）。固定門限的「低熵答錯=學錯」58 筆在三分位下大部分被重分到中／高熵——因全體中位數僅 ~0.085，絕對 0.5 門限對「低」過寬。

## Fano 下界

形式：

```
H(X|Y) ≤ h(P_e) + P_e · log₂(|X| − 1)
```

假設：每位視為 |X|=M 的同音分類；H 取限制在 C_i 後的殘餘熵。

全體：H̄=0.444 bits，M̄=10.77

| 形式 | P_e 下界 |
|------|----------|
| 標準 Fano（數值反解） | **0.0491** |
| 弱化式 (H−1)/log₂(M) | 0（H&lt;1 時無資訊） |

→ 字級正確率「名義」上界 ≤ **95.09%**。  
**但出貨已達 96.51%**，高於該名義上界 → 說明此 H **不是**嚴格意義上決策過程的 H(X\|Y)（前綴／候選集合／與 walk 融合的生成過程不一致）。  

**用途**：只能當量級剎車（錯誤不可能任意小），**不能**反推「還能再救幾句」。油門無效。
