## 方法（閘門）

1. `flip_proposal_dump` 自出貨輸出產生**全部**單字同音翻提案（66,408 條），`Δscore = v2c(S')−v2c(S)`。
2. 每句最多接受 **1** 個通過閘門且 Δ 最大的提案（單輪；與棒 A 兩輪略有差異，V1 對齊棒 A 第 1 輪 −48）。
3. 閘門：`Δ ≥ δ_min` 且可選 `H ≥ h_min`（H = 該位置 gold 前綴殘餘熵）。
4. 格點：δ ∈ {0, 0.05, 0.1, 0.2, 0.5, 1, 1.5, 2, 3}；H_min ∈ {0, 0.1, 0.25, 0.5, 0.75, 1, 1.5, 2}。
5. 曲面完整輸出：`tw538-flip-gate-sweep.tsv`。

### V3 高原檢查

最佳點 δ=2.0, H≥0.1, net=+5。  
鄰格 nets：`[(1.5,0)=+1, (1.5,0.1)=+3, (1.5,0.25)=+2, (2,0)=+3, (2,0.25)=+4, (3,0)=+2, …]`  
**同值鄰格 = 0**，within1 僅 1 → **偏孤立尖峰，不可當穩健操作點**。

### V4 為何恒為 0（重要負結果）

出貨路徑**本來就是** n-best 上 `walkScore + ν·v2c`（ν=0.75）的 argmax。  
用同一 fused 分數在 n-best 上重選 → **永遠選回出貨**，接受數恒 0。  
把 walk 加回「路徑級」翻字判準，在現行出貨定義下是**同義反覆**，救不了 REGRESS。

### V5 誠信註

「只翻 gold_rank=1 且位置答錯」的 85 個位置：在 gold 前綴下 top1=gold≠pred。  
這是 **用 gold 標出的位置過濾（半 oracle）**，**不能直接當上線閘門**。  
即便如此，held-out 平均淨增益僅 **+7.95**，仍 **&lt; +15**。

| 門檻 | 結果 |
|------|------|
| ≥+30 GO | 無 |
| +15~+29 邊際 | 無（V5 held-out +7.95 未達） |
| &lt;+15 NO-GO | **全部變體** |

### **判定：NO-GO**

- 可部署的 V2/V3 held-out 淨增益 ≈ **0～+1**，且 V3 為孤立尖峰。  
- V4 空操作。  
- V5 半 oracle 最好也只有 held-out **+8** 左右，**遠低於 +30 GO 線**，也低於 +15 邊際線。  

**負結果等價正結果**：單點同音翻字（含 Δ／H 閘門、含 walk 融合、含 rank1 位置限制）**不構成可訓練／可出貨的下一棒**；建議正式關閉此路線，不開棒 C。
