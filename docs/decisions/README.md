# docs/decisions — 決策脈絡

**這裡放「為什麼這樣做、試過什麼、排除了什麼」。只增不改，要動某個領域之前才讀。**

在這個目錄出現之前，決策脈絡在 repo 裡沒有家，只好塞進一份放在 repo 外的
「軍師交接檔」—— 於是它 ① CI 看不到 ② 派 grok 時 `--cwd` 涵蓋不到 ③ 被丟進垃圾桶沒人發現
④ 內容跟 `AI_HANDOFF_PROMPT.md` 重疊必然漂移。給它正式的家，那份檔就自然解散
（2026-08-13 已拆解刪除）。

## 分工（別放錯層）

| 要寫的東西 | 該去哪 |
|---|---|
| 建置、慣例、關卡、收工清單 | `AGENTS.md` |
| 到哪了、下一刀 | `AI_HANDOFF_PROMPT.md`（一頁） |
| 版號、每版發了什麼 | `CHANGELOG.md` + plist |
| **為什麼、試過什麼** | **本目錄** |
| 外部文獻／方法調查、外勤原始回報 | `docs/research/` |
| 已證明無效 | `docs/dead-ends.md` |
| 過往交班日誌 | `AI_HANDOFF_ARCHIVE.md` |

## 寫法

- 一篇一個決定，檔名 `NNNN-一句話結論.md`，開頭寫「決定 / 為什麼 / 什麼會推翻它」。
- **不寫版號、不寫現況數字。** 那兩層有自己的真源（plist + CHANGELOG），抄了就會漂。
- 決定被推翻時**不要刪掉舊篇**，在篇尾補「後續」並寫清楚被什麼證據推翻。
- **例外：健檢類的活文件**（目前只有 `0010`）會被重複量測、就地更新數字。
  這類必須在開頭標明「量測過幾次、以哪一次為準」，否則會被誤讀成凍結快照。
